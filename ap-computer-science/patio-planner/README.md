# Patio Planner

A Java exercise that models a sloped patio and compares measured paver heights with the expected heights.

From this folder, run `javac -d out src/*.java` and `java -cp out BuildIt`. Enter the patio width, length, and height at the far edge, then the paver width and length, one value per line. For each paver, enter its two measured edge heights as a comma-separated pair.
