# Playfair Cipher

A Java console exercise that builds a key table and encrypts or decrypts pairs of letters with a classical Playfair cipher. This is an educational demonstration, not modern encryption.

From this folder, run `javac -d out src/*.java` and `java -cp out PlayfairCipher`. Use lowercase letters for the key and messages.
