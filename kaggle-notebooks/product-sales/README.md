# Product Sales

This [notebook](predicting_product_sales.ipynb) engineers date and category features and compares regression models for forecasting product sales. It uses pandas, scikit-learn, and XGBoost.

Download the training and test CSVs from the [September 2022 Tabular Playground](https://www.kaggle.com/competitions/tabular-playground-series-sep-2022/data), then follow the [collection setup](../).
