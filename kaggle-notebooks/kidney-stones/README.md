# Kidney Stones

This [notebook](kidney_stone_predictions.ipynb) explores binary prediction from tabular measurements using pandas and scikit-learn. It compares models and evaluates predictions with ROC AUC.

Download the training and test CSVs from [Kaggle Playground Series S3E12](https://www.kaggle.com/competitions/playground-series-s3e12/data), then follow the [collection setup](../).
