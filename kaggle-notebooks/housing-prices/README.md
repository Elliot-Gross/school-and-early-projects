# Housing Prices

This [notebook](predicting_housing_prices.ipynb) compares linear, tree-based, and boosted regressors for predicting housing sale prices. It uses pandas, scikit-learn, XGBoost, and LightGBM.

Download the training and test CSVs from [Kaggle Playground Series S3E1](https://www.kaggle.com/competitions/playground-series-s3e1/data), then follow the [collection setup](../).
