# Kaggle Notebooks

Five competition notebooks covering tabular regression, classification, and feature engineering. The snapshot preserves the code cells but omits saved execution outputs, competition data, and generated submissions.

Open a notebook in Colab or Jupyter. Download the competition data linked in its README, update the original Google Drive paths, and install the Python packages imported by the notebook. For local Jupyter, skip the Colab Drive-mount cells.
