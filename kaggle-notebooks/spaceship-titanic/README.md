# Spaceship Titanic

This [notebook](space_titanic.ipynb) imputes missing values, selects features, and compares classifiers that predict whether passengers were transported. It uses pandas, scikit-learn, and XGBoost.

Download the training and test CSVs from [Kaggle's Spaceship Titanic competition](https://www.kaggle.com/competitions/spaceship-titanic/data), then follow the [collection setup](../).
