# Rocket League

This [notebook](rocket_league_predictions.ipynb) uses distances, dimensionality reduction, and an XGBoost classifier to predict which team will score next.

Get the raw files from the [October 2022 Tabular Playground](https://www.kaggle.com/competitions/tabular-playground-series-oct-2022/data) and follow the [collection setup](../). The final submission cell expects a preprocessed `X_test.csv` that was not in the source repo; the raw competition files alone are not enough to rerun that cell unchanged.
