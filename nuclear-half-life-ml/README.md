# Nuclear Half-Life ML

A notebook study of isotope half-lives: cleaning and visualizing isotope data, engineering physics-inspired features, and comparing regression models. The main stack is Python, pandas, scikit-learn, and Keras. See the [original project abstract](https://github.com/Elliot-Gross/Nuclear-ML-Project/blob/bf3528fd32c30006eb3caf09b12652b8804d150b/Abstract%20Final.pdf) for the study summary.

Start with [data cleaning and exploration](data-cleaning-and-exploration/), then see [feature engineering](feature-engineering/) and [predictions](predictions/). The notebooks retain their original Colab paths. To rerun them, update those paths and use the CSVs in the [pinned source tree](https://github.com/Elliot-Gross/Nuclear-ML-Project/tree/bf3528fd32c30006eb3caf09b12652b8804d150b) or regenerate them from the notebooks. The collection notebook documents [periodictable.com](https://periodictable.com/) as its source.
