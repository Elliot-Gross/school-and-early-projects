# School & Early Projects

A selection of Elliot Gross's early programming projects, from AP Computer Science and a ranked-choice election counter to Kaggle notebooks and a desktop audio notetaker.

These are historical snapshots, not maintained applications. Each project README lists its source commit and any prerequisites. The year in the index is the year of the snapshot.

## Project index

| Project | Year | What it does | Stack |
| --- | --- | --- | --- |
| [AutoTranscribe](autotranscribe/) | 2023 | Transcribes an audio file and turns it into Markdown notes. | Python, Tkinter, OpenAI API |
| [Ranked-Choice Election](ranked-choice-election/) | 2020 | Counts ranked ballots to select multiple winners. | Python, pandas, NumPy |
| [Nuclear Half-Life ML](nuclear-half-life-ml/) | 2023 | Explores isotope features and compares half-life regression models. | Python, Jupyter, scikit-learn, Keras |
| [Portfolio Optimizer](portfolio-optimizer/) | 2021 | Turns historical closing prices into a sample stock allocation. | Python, Jupyter, PyPortfolioOpt |
| [Playfair Cipher](ap-computer-science/playfair-cipher/) | 2021 | Encrypts and decrypts letter pairs with a classical cipher. | Java |
| [Stock Simulator](ap-computer-science/stock-simulator/) | 2021 | Simulates a year in a fictional market using randomized prices. | Java |
| [Fibonacci](ap-computer-science/fibonacci/) | 2021 | Compares approaches to calculating Fibonacci numbers. | Java |
